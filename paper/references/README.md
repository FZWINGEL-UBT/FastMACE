# Copies of the references

Source: an owner request (11 November 2026, "make sure all references are downloaded in the branch"). The
files were downloaded on 11 November 2026 by Haiku subagents through one helper script, and each PDF was then
checked independently: the words of its bibliography title were searched for on its first two pages, and the
arXiv stamp on page 1 was compared with the address it came from. Every PDF listed here passed. One file,
`thompson2022lammps.pdf`, was downloaded by the owner in a browser and checked the same way.

Each file is named after its key in `../references.bib`.

**Only free, legal copies.** Sources are arXiv, a publisher's own free copy, the official proceedings, or a
copy hosted by an author or their institution. Where the published version sits behind a paywall or a robot
check, the preprint or accepted manuscript is saved instead and the table says so. Nothing was taken from
shadow libraries, and no paywall or robot check was worked around.

**Before this repository becomes public,** check each file's licence. arXiv's default licence lets arXiv
distribute a paper; it does not let others redistribute it. Publisher and author-hosted copies have their own
terms. The README and citation snapshots come from repositories with open-source licences (named below).

## How to repeat or extend

The helper and the check are not part of this folder, so that nothing here is executable. To add a reference:
download it from a source of the kinds named above, name it after its bibliography key, and add a row with its
source, page count, size and SHA-256.

Committed files in this folder: 162.2 MB in total.
