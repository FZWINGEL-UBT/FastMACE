# OPT10-T04: evict-first cache hints on the streaming kernels' `w` (29 October 2026)

Plan: `plans/opt-10.md`. Tool: `tools/bench/opt10_cache_hints.py` (source `b0ff0a4f`). Records:
`results/opt10-T04-cache-hints-20261029/`.

**Verdict: faster in both build orders on the RTX 4000 Ada, exact.** NaNbO3 0.980 / 0.980, NbCl5 0.988 / 0.989
of the default step. Under decision 66 this qualifies for a per-GPU default on the RTX 4000 Ada once it is a
record. **Neutral on the RTX 5060 Ti** (local, 29 October, same tool and protocol; `local-rtx5060ti-*.json`):
NaNbO3 1.0024 / 0.9986, NbCl5 1.0027 / 0.9974, so it stays off there. An A100 A/B is not done.

## What changes

`w [E, 1280]` is written once by `fused_folded_forward` and read once by the convolution backward. Side b compiles
the vendored kernels with `__stcs` on the fused forward's `w` stores and `__ldcs` on the streaming kernels' `w`
loads (L2 evict-first). Values are unchanged, so the step is bitwise the same arithmetic. The tool rewrites the
rendered CUDA source inside `runtime.compile_cubin` while side b is built and counts the substitutions: 70 loads
and 3 stores per build in every run (a run is invalid without both).
