# 3-T10: displacement moves

Plan task 3-T10 (`plans/phase-3.md`), 22 October 2026. Spec: §10.4 "Proposals", "Fixed positions
versus displacements", "Graph capture"; §8.5 step 4; §12.2 "Mutation events".

## What exists now

- **`fastmace/mc/displace.py`.**
  - `decode_displace`: one atom chosen uniformly, then a uniform point in a sphere of radius δ.
    Each attempt draws 5 proposal numbers and 1 acceptance number, whatever its outcome.
  - `check_displace`: refuses a variable cell (`displace-variable-cell`) and a `delta_A` above
    `Workload.max_displacement_A` (`displace-beyond-max-displacement`).
  - `DisplaceAttempt`: the attempt of a `Displace` move in the shape of 3-T09's `Attempt`, built by
    `moves.build_attempt` and run by `MCDriver`.
- **In `MCDriver`** (after 3-T09 merged):
  - `attach(..., max_displacement_A=)` runs `check_displace`;
  - `run_block` handles halted displacement attempts;
  - the block record gives `trial_rebuilds`, `delta_A` and, with `adaptive`, `adapted_delta_A`;
  - the restart's `delta_A` keeps each move's δ.
- **Two paths per attempt.**
  - **Captured attempt:** propose, apply, rebuild test, compact, energy, decide, masked restore,
    compact again. It is valid only when the rebuild test passes and the count fits the active
    edges. Otherwise it restores itself and halts: the attempt index stays and later replays do
    nothing.
  - **Host path:** runs the halted attempt again with the same numbers. It saves the committed
    list, applies the move and, if needed, builds the list eagerly around the trial geometry
    (`GraphEngine.trial_rebuild`). It sizes the edges for the trial and runs the captured energy
    graph. An accepted move keeps the trial list; a rejected one restores the position and the
    list. Nothing is re-tested at the restored positions, so nothing loops.
  - The host reads the device once after a displacement move's replays, plus once per halted
    attempt.
- **Overflows** are redone with the same numbers:
  - edges beyond the active size halt the captured attempt;
  - a trial build that grows the capacity restores the position, rebuilds at the committed
    positions and redoes the attempt.

  Both count in `overflows_redone`.
- **Beside it:**
  - `SkinNeighbourList.save_list` and `restore_list`;
  - `GraphEngine.trial_rebuild`, `use_trial_edges`, `adopt_trial_list` and
    `record_mc_overflow`.

  The names are in `docs/design/contracts-3.md` ("Displacements (T10)") and pinned in
  `tests/cpu/test_contracts_3.py`.

## Cost: one displacement attempt, with and without a trial rebuild

- **Machine:** local PC, NVIDIA GeForce RTX 5060 Ti, WSL.
- **Environment:** `~/environments/mace_cueq_oeq` (in-process OEq runtime).
- **Model:** MH-1 `mh1-r2scan` (`~/models/mace-mh-1.model`).
- **Plan:** hybrid float32. The workload is `Workload(mc_moves=("displace",), max_displacement_A=0.1)`
  at 300 K, so rule 11's skin is 0.5 Å.
- **Structures:** 3×3×3, from the 1a-T18 baseline export.
- **Commit:** FastMACE branch `fastmace/3-T10`.
  - The NaCl and NbCl5 runs used the tool as committed in d6f5bf7 (the `--displace-trial-attempts`
    commit; the code ran uncommitted, identical).
  - The `NaCl-trial10` run used 42ea43c.
  - The tool's own `fastmace_commit` field is empty: WSL git cannot read a Windows worktree's
    `.git` file.
- **Baseline:** none. The research engine has no displacement moves.
- **Protocol:** `tools/bench/mc_cost.py --displace-delta-A 0.1 --block 20 --rounds 8 --warmup 100`.
  - All sides run in one process, in alternating blocks; the order rotates and is mirrored.
  - Every attempt is rejected against a baseline 1000 eV below the state, so the MD state stays
    as it is.
  - **Graph side:** δ = 0.1 Å, 10 attempts per call.
  - **Trial side:** δ = the skin, 1 attempt per call. About 87 % of its attempts take a trial
    build.
  - The per-attempt costs of the two paths are solved from the two sides: t = (1 − f)·t_graph +
    f·t_host.
- **Load:** the GPU was reserved through `tools/ci/local_gpu.py`. Other workers' CPU work may have
  run at the same time; the PC was not verified quiet. The spread is 1.4–1.8 % on the graph side
  and 17–18 % on the trial side (host syncs and an eager build).

## Findings

1. **A captured attempt costs about 0.9–1.0 ms more than an energy-only evaluation** (NaCl
   2.10 ms against 1.19 ms; NbCl5 10.0 ms against 9.0 ms).
   - The extra work is fixed per attempt: two compactions over all candidates, the rebuild test,
     the Philox numbers, and one call's host reads per 10 attempts.
   - It is not profiled yet.
   - A candidate saving: restore the compacted edges from a copy instead of compacting again,
     only where a copy is cheaper.
2. **A trial-rebuild attempt costs 1.5–5.7 MD steps**, plus the replays a halt wastes in its
   block. Rule 11 sizes the skin so that these attempts stay rare; the rate is recorded per move
   (`trial_rebuilds`).
   - If a workload makes them frequent, the waste can be cut by replaying in smaller chunks. That
     costs one more host read per chunk.
3. **Not wired yet:** T09's `MCDriver` does not dispatch `Displace` to `DisplaceAttempts`, because
   the driver is not on main yet. `moves.build_attempt` and the `displace` kind of
   `events.Transaction` still raise their stubs. The integration is one small change after T09
   merges:
   - the driver passes its stream offsets, the block baseline and `Workload.max_displacement_A`;
   - it calls `run`;
   - it ends a block with an acceptance at its canonical point.
