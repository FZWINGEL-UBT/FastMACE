On the GPU, the plan with a switch is not reproducible (hybrid OEq and cuEq kernels use atomics), so the
interrupted-after-the-switch comparison there is statistical. The bitwise check is the CPU one, on the
same code path. A `reproducible=True` plan never switches (decision 53).
