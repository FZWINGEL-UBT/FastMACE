# 3-T15 front ends: local GPU smoke

Plan task 3-T15 (`plans/phase-3.md`): `Simulation.run(mc=…)`, `fm.md(mc=…)`, the CLI `[[mc]]`
tables, the report's MC line, `counters.mc` and the thermo MC columns. The CPU tests cover the
logic on T09's driver; this smoke runs `fm.md` with a swap block on the GPU, then a resume.

- **Setup:**
  - local PC, NVIDIA GeForce RTX 5060 Ti, WSL;
  - `~/environments/mace_cueq_oeq` (OEq runtime prepared in process);
  - MH-1 `mh1-r2scan` (`~/models/mace-mh-1.model`), default planner: graph tier, hybrid cuEq/OEq,
    float32, MC energies in the force precision;
  - NaCl 3×3×3 (216 atoms) from the 1a-T18 baseline export; NVT Langevin 0.5 fs at 1000 K, seed 1.
- **Commit:** FastMACE `fastmace/3-T15` at 92691c9 (main 22c1e73 holds the same code). Baseline:
  none (no research-engine counterpart).
- **Protocol:** `tools/validation/mc_front_end_smoke.py`, through `tools/ci/local_gpu.py run`.
  1. `fm.md`, 1,200 steps, `fm.mc.Swap(pairs=[("Na", "Cl")], every=100, attempts=50)`, thermo every
     50 steps, restart every 300;
  2. `Simulation.resume` of the run directory (the restart at step 1,200), then 600 more steps with
     the move set still attached.
- **Results:** `results/3-T15-rtx5060ti-20261022/NaCl/smoke.json`. All four checks pass.

| Check | Result |
| --- | --- |
| `counters.mc.swap.attempted` = blocks × attempts (12 × 50) | 600, pass |
| the report's cost line has a device time per attempt | 2 ms/attempt over 11 timed blocks (550 attempts; the first block, with its captures, left out), pass |
| the last thermo row's `mc_swap_attempted` and `mc_swap_accepted` equal the counters | 600 and 0, pass |
| after the resume the counters continue from the restart's | 600 at the resume, 900 after 6 more blocks, pass |

No swap was accepted: Na ↔ Cl in rock salt costs several eV, far above k_B T at 1000 K. The
per-attempt cost agrees with 3-T09's measurement (1.78 ms for a float32 swap attempt on NaCl, its
`docs/validation/3-T09.md`).

The report after the run:

```text
mc:      swap Na-Cl every 100, 50 attempts (exchange); accepted 0/600; 2 ms/attempt over 12 blocks (device time; each attach's first block, with its captures, left out); attached over steps 0–1,200
speed:   8.01 ms/step, whole-run mean over steps 1–1,200
```

## Findings

1. **The speed line includes the MC blocks.** The whole-run mean is the loop time over the MD steps,
   and the blocks run inside the loop: 8.01 ms/step here, against about 2.9 ms for MD alone (3-T09).
   The MC line gives the blocks' own cost. Whether the speed line should leave the blocks out is a
   report decision, not made here.
2. **A resumed run's report says `output: none`** although it writes into the run directory.
   `Simulation._resume` builds the report before it sets `self.output`. This predates 3-T15.
3. **The resumed run's mean (21.1 ms/step over 600 steps)** includes the first step's captures
   after the resume and the first block's attempt captures. Expected for a short run.
