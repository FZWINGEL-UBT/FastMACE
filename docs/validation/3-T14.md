# 3-T14: the swap-MC annealing protocol, end to end

22 October 2026. Branch `fastmace/3-T14`. Plan task 3-T14, acceptance item 9 of phase 3 (SPEC §16 row 3,
§10.5; owner decision D3 = SPEC §18 decision 33).

**Result:** the protocol ran end to end at 1 fs, on the local RTX 5060 Ti and on an Ada GPU (leeloo):
- the initial relaxation;
- MD along the anneal schedule with the swap block attached from 250 K on;
- the move-energy gate (passed on every piece);
- a mid-run restart and resume;
- the quench of 21 frames;
- the attempt and acceptance counters in the output.

No O↔Cl swap was accepted: 0 of 132,550 attempts in each full run. The owner judged the item on the code,
not on the acceptance rate (22 October 2026): "just having this functionality is fine as long as the code
works". **Choosing which species to swap, and with which moves, is a separate project.**

## The protocol

`fastmace/protocols/data/swap_anneal_NaNbOCl4.toml`, run with `fastmace run swap_anneal_NaNbOCl4`:

| Item | Setting |
| --- | --- |
| Structure | NaNbOCl4, the Ma 2026 I4/m polymorph (`NaNbOCl4_I4m_Ma2026.cif`, source in `data/SOURCES.md`), 3×3×3: 756 atoms. The file is P1 with a = 8.304 Å, b = 9.875 Å, γ = 89.52°, used as given |
| Model | MH-1, head `matpes_r2scan`; hybrid cuEq/OEq, float32 |
| Relaxation | ASE LBFGS at fixed cell to fmax 0.01 eV/Å (`fm.calc`, float32) |
| Schedule | the `anneal` profile at 1 fs: 0 → 1000 K in 20 ps, then 3 K/ps to 250 K (270,000 steps) |
| MC | `Swap(pairs=[("O", "Cl")], every=100, attempts=50, velocities="exchange")`, `min_mc_temperature_K=250`: attached over steps 4,999–270,000 |
| MC energy precision | from the move-energy gate (3-T11): float32 when it passes |
| Output | frames and thermo rows every 10 steps (10 fs), a restart every 10,000 steps (10 ps) |
| Quench | the anneal profile's: 2 frames per 100 K bin from 500 K on each ramp, and the final frame; LBFGS to fmax 0.01 eV/Å |

The runs went in two pieces of 135,000 steps: `fastmace run … --steps 135000`, then
`fastmace run --resume RUN_DIR --steps 135000`, which ran to the end and quenched.

### Why: the attempted ΔE (indicative)

`swap_statistics.py` evaluates sampled O–Cl swaps on saved frames as the exchange of the two atoms'
positions (`fm.calc`, float32). On the local smoke's frames (1 frame and 2 swaps per bin, so only
indicative; `smoke-local-20261022a/swap_energies_indicative.*`):
- ΔE/kT at the bin's target had a median of about 110–470 in every bin, from 250 to 1000 K, on both
  ramps;
- the minimum was 107;
- the mean Metropolis probability was below 1e-47 everywhere.

That is ΔE ≈ 9–11 eV per unrelaxed swap. Nb–O is 1.756 Å in the structure and Nb–Cl 2.364 Å, so an
exchanged Cl lands 1.76 Å from Nb. A full ΔE sample (4 frames × 50 swaps per bin) and an Nb↔Ta
comparison (`nbta_swaps.py`, D3 option b) were prepared and then dropped on the owner's decision. Both
scripts are committed for the later swap project.

## What changed (code)

- `fastmace/protocols/data/`: the protocol, a short variant (27,000 steps, for a paid GPU), the CIF and
  `SOURCES.md`, shipped with the package.
- `fastmace/protocols/quench.py`: ports of the research engine's relaxation, `select_frames` and the
  quench loop. Frames are read per pick from the output chunks. An interrupted quench continues.
- `fastmace/protocols/runner.py`:
  - `start`: the relaxation, then `fm.md` for at most `--steps` steps, then a restart;
  - `resume`: the move set attached as `fm.md` attaches it, and kept across a resume;
  - the quench after the last step;
  - `protocol.json`.
- `fastmace run`:
  - a shipped protocol name or a file;
  - `[relax]` and `[quench]` tables;
  - `--steps`, `--resume RUN_DIR` and `--output`;
  - `.yaml`/`.yml` configs read with `safe_load`. `mace_cueq_oeq` is Python 3.10 without `tomli`.
- `fm.md` with `steps=` and a schedule now sizes `max_temperature_K` from the whole schedule (§7.7), so the
  rest runs later on the same plan.
- Tests: `tests/cpu/test_swap_anneal_protocol.py`. In it, a tiny CPU protocol run in three pieces equals
  the same run in one go, bitwise, across accepted swaps. Plus a contract pin in
  `tests/cpu/test_contracts_3.py`.
