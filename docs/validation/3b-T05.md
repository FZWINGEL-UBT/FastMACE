Status: **the pressure setter is done**. D3 in the NPT path and the comparison of conductor's choice 7
follow after 3b-T04 merges. Plan: [phase-3b.md](../../plans/phase-3b.md), task 3b-T05. Spec: §10.1

## The pressure setter (SPEC §10.1)

- `LangevinBAOAB.set_pressure(pressure_GPa)` and `set_external_stress(stress_GPa)` take GPa, ASE sign:
  a scalar, or six Voigt components for the full cell, with `IntegratorConfig.external_stress_GPa`'s
  validation. `set_externalstress(value)` takes ASE units, the constructor keyword's forms.
- Each is a `copy_` into the device tensor `externalstress`, which the captured graphs read: no
  recapture, no quiesce. The arithmetic is the config's, so a target filled to P equals one configured
  with P bit for bit.
- Fixed-cell integrators (`Langevin`) refuse both setters (`NotImplementedError`).
- **Half-step lag** (approved by the conductor): the new target enters at the next step's cell-force
  update, so that step's first barostat half kick still uses the previous target. The same happens in
  ASE when `externalstress` is replaced between steps.
- **Restart:** the integrator record stores the current target exactly, in ASE units
  (`"externalstress"`). `restart.restore_targets` fills temperature and pressure on resume, and
  `Simulation._resume` uses it. Files from before 3b-T05 keep the configured target.

### The double buffer

**Bug found and fixed:** stage B must not read the filled target directly. A pipelined engine
validates step n inside step n+1's call, after the host has filled step n+1's target. When it redoes
B(n) (rebuild or edge-count overflow), B(n) saw target(n+1). Under a pressure ramp, pipelined and
checked engines then differed by up to 1e-4 Å.

**The fix:** BAOAB keeps a second tensor, `externalstress_step`:
- stage A copies the filled target into it;
- stage B's `_update_force_eps` (and the registry's refresh of the cell force) reads it;
- a resume fills both tensors.

The temperature fill never had this problem, because `sqrt_kT` is read only in stage A. Both tensors
are registered (derived; [contracts-1b](../design/contracts-1b.md) table).

### Tests (CPU, float64)

`tests/cpu/test_pressure_setter.py`, 25 tests:
- **ASE match:** a 0 → 2 GPa ramp reproduces ASE `LangevinBAOAB` whose `externalstress` is replaced
  between steps, hydrostatic and full cell, within 1e-9.
- **The fill:** in place (same tensor, same address); Voigt components; a filled target equals a
  configured one bit for bit.
- **Pipelined:** pipelined replayed engines equal eager ones under a ramp, with a count redo forced
  after a fill. With `externalstress_step` aliased to the filled target (the bug), both cell modes
  fail.
- **Restart:** the record holds the current target; an interrupted ramp resumes bit for bit, in
  checked and pipelined modes and both cell modes, with a target at the restart that differs from the
  configured one. Old files keep the configured target.
- **Refusals:** fixed-cell integrators, non-finite, boolean or malformed targets, and Voigt components
  for a hydrostatic cell.

CPU suite (22 October 2026, `fastmace_cpu`, commit 15f0561, `-n 6`, `-m "not slow and not
acceptance"`): 3162 passed, 242 skipped. Ruff clean.

### GPU: the copy changes no numbers, and its cost

`LangevinBAOAB` committed on `main` (7b11730, identical to this branch's base) next to the current one in

deterministic Lennard-Jones (argon 3×3×3, 108 atoms, float64), 2000 steps, 1701 neighbour rebuilds per
engine.

- **Machine and run:** the PC, NVIDIA GeForce RTX 5060 Ti (WSL2), `~/environments/mace_cueq_latest`

**Cost:** pipelined hydrostatic engines, 500 warm-up steps, then 10 alternating blocks of 2000 steps.
- Medians: 1106.5 µs per step with the copy, 1106.3 µs without.
- Median difference +6 µs, but the block differences range from −44 to +37 µs, so the cost is **not
  resolved** at this size. The Lennard-Jones step is host-bound (about 1.1 ms of Python per step).
- The copy is one 1- or 9-element device copy, one more kernel node in graph A: a few µs at most.
  Against NbCl5's 29 ms production step that is below 0.03 %.
